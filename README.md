# Random Fitness 🎲💪

Случайное упражнение на случайное число повторений. Работает как обычный сайт (ПК и телефон) и как **Telegram Mini App**. Авторизация нужна только чтобы сохранять статистику — покрутить упражнения можно и гостем.

- Категории упражнений + категория **«Все упражнения»**
- Рулетка: случайное упражнение → случайное число повторов в диапазоне упражнения
- Статистика: всего повторов/подходов, активные дни, серия дней подряд, разбивка по упражнениям, последние подходы
- Два способа входа: логин/пароль (веб) и Telegram (проверка подписи `initData`)
- Node + Express + SQLite, всё в одном контейнере, порт **7703**

## Быстрый старт (Docker)

```bash
cp .env.example .env          # впишите JWT_SECRET (и BOT_TOKEN, если нужен Telegram)
docker compose up -d --build
```

Откройте http://localhost:7703

База данных лежит в `./data/app.db` (том примонтирован, переживает пересборку).

### Без Telegram
Можно вообще не задавать `BOT_TOKEN` — сайт полностью работает с входом по логину/паролю. Вход через Telegram просто будет недоступен.

## Локальный запуск без Docker

```bash
npm install
JWT_SECRET=dev-secret PORT=7703 npm start
```

## Переменные окружения

| Переменная   | По умолчанию         | Назначение                                   |
|--------------|----------------------|----------------------------------------------|
| `PORT`       | `7703`               | Порт сервера                                 |
| `JWT_SECRET` | `dev-secret-change-me` | Секрет для подписи сессий — **задайте свой** |

## Подключение Telegram Mini App

1. Разверните приложение так, чтобы оно было доступно по **HTTPS** (Telegram требует https).
   Для 7703 обычно ставят обратный прокси (nginx/Caddy/Traefik) с доменом и TLS.
2. В [@BotFather](https://t.me/BotFather): `/newbot` — получите `BOT_TOKEN`, впишите его в `.env`, перезапустите контейнер.
3. Там же `/newapp` (или Bot Settings → Configure Mini App) — укажите URL вашего сайта.
4. Готово: при открытии из Telegram приложение само авторизует пользователя по `initData`
   (подпись проверяется на сервере через HMAC-SHA256 с `BOT_TOKEN`).

Подпись валидируется по официальному алгоритму Telegram, свежесть `auth_date` — не старше 24 часов.

## Админка

Отдельная вкладка **«Админка»** появляется в интерфейсе только у администраторов. Оттуда можно добавлять, редактировать и удалять упражнения и категории — без захода на сервер и правки кода.

Кто админ — задаётся окружением (можно менять на лету, доступ обновляется при следующем запросе):

```env
ADMIN_USERS=ironmax,anna          # веб-логины через запятую
ADMIN_TELEGRAM_IDS=777000111       # и/или Telegram ID (узнать свой: @userinfobot)
```

Как назначить первого админа: зарегистрируйтесь в приложении под нужным логином, впишите его в `ADMIN_USERS`, перезапустите контейнер (`docker compose up -d`) — вкладка появится после перезахода.

Правила безопасности, встроенные в админку:
- нельзя удалить упражнение, по которому уже есть записанные подходы (чтобы не терять историю) — только редактировать;
- нельзя удалить непустую категорию;
- валидация: название 2–60 символов, повторы — целые ≥ 1, минимум ≤ максимума, единица «раз» или «сек».

## Как добавить упражнения

Проще всего — через **админку** в интерфейсе (см. выше). Стартовый набор упражнений задаётся
в функции `seed()` в `server.js` и заливается только при первом запуске на пустой базе.
Чтобы пересеять с нуля — остановите контейнер и удалите `data/app.db*`, затем запустите снова.
Единица `сек` вместо `раз` поддерживается для планки/лодочки и т.п.
